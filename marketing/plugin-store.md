Bugsnag connects Craft's server and browser errors to the error-monitoring workflow your team already uses. Capture useful context automatically, then add the breadcrumbs and metadata that make a report actionable.

An error report that only says something broke is barely a head start. Send Craft exceptions and selected log messages to Bugsnag with the release, request and user context needed to understand where the problem happened.

## Features

- Send Craft and PHP failures to the correct Bugsnag project automatically.
- Forward selected warning and error categories with configurable exclusions.
- Initialise Bugsnag's browser client with settings exposed safely to Twig.
- Record the events that led to a failure from PHP, Twig, or Craft Commerce.
- Remove passwords and other nominated values before reports leave the site.
- Set release stages, application versions, user data, and ignored traffic per project.
