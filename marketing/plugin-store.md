Bugsnag connects Craft’s server and browser errors to the error-monitoring workflow your team already uses. Capture useful context automatically, then add the breadcrumbs and metadata that make a report actionable.

An error report that only says something broke is barely a head start. Send Craft exceptions and selected log messages to Bugsnag with the release, request and user context needed to understand where the problem happened.

## Features

- **Exception reporting:** Send Craft and PHP failures to the correct Bugsnag project automatically.
- **Yii log target:** Forward selected warning and error categories with configurable exclusions.
- **Browser monitoring:** Initialise Bugsnag’s browser client with settings exposed safely to Twig.
- **Breadcrumbs:** Record the events that led to a failure from PHP, Twig, or Craft Commerce.
- **Payload filters:** Remove passwords and other nominated values before reports leave the site.
- **Environment controls:** Set release stages, application versions, user data, and ignored traffic per project.
- **Follow the trail:** Add browser errors, breadcrumbs and optional Commerce context without including payment or address details.
